# One-Line Office Joke

An entry for the make.fun "One-Line Office Joke Laugh-Off" bounty.

## What it is

One original one-line joke about office life: the team's supposedly
"quick sync" meeting has been going on so long it now has a calendar
invite of its own — it has outlasted most of the people who work there.

## How to run

```sh
python3 main.py
```

## Output

The joke is written to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`
when `OUTPUT_DIR` is set): one line, UTF-8, nothing else in the file.
